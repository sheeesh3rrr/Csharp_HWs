1. Прочитать небольшой конфигурационный файл (10 строк) целиком
File
Объяснение: Файл очень маленький, поэтому его безопасно и удобно загрузить в оперативную память за один вызов без ручного управления потоками.

2. Автосохранение прогресса игры (позиция, здоровье, инвентарь)
File 
Объяснение: Для небольших текстовых сохранений (как JSON) достаточно простого File.WriteAllText, который сам откроет, перезапишет и закроет файл. 

3. Дописывание строк в конец лог-файла размером в несколько гигабайт
FileStream
Объяснение: При частой записи в гигабайтный файл держать поток открытым и дописывать данные в конец через буфер FileStream намного быстрее и эффективнее, чем каждый раз заново открывать и закрывать файл через File.

4. Проверить существование файла сохранения и прочитать его целиком в строку
File
Объяснение: Класс File предоставляет готовые однострочные методы как для проверки наличия файла на диске, так и для его полного чтения в строку.

5. Заменить 10 байт в середине большого бинарного файла без полной перезаписи
FileStream 
Объяснение: Только FileStream поддерживает произвольный доступ внутри файла, позволяя переместить курсор на нужное смещение в байтах и точечно перезаписать участок, не загружая гигабайты данных в память.
