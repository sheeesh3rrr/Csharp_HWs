1) File - файл маленький и его можно прочитать целиком
2) File - можно просто перезаписывать файл при каждом автосохранении
3) FileStream - работа с большими файлами, позволяет дописывать данные не сохраняя весь файл
4) File - сначала проверим файл, а позже прочитаем его, тоже работа с небольшим файлом
5) FileStream - позволяет переместиться в нужное место и поменять что-то, не перезаписывая файл целиком
