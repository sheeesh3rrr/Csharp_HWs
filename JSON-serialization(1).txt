а) Какие поля/свойства попадут в JSON, а какие нет?

В результате попадут только публичные свойства:
-Name — попадёт. Это публичное свойство. Json по умолчанию сериализует только публичные свойства.
-Score — попадёт. Аналогично. Это публичное свойство, доступное для чтения.

-secretCode — не попадёт. Оно имеет модификатор доступа private. Это поле, а не свойство. Сериализатор игнорирует приватные члены класса.
-IsAlive — не попадёт. Это поле, а не свойство (отсутствуют { get; set; }), а Json по умолчанию игнорирует все поля.


б) Как сериализовать secretCode, оставив его private?

Его нужно пометить атрибутом [JsonInclude], чтобы System.Text.Json оставил приватное поле или свойство в JSON.
 

в) Почему IsAlive не попадает в JSON?

Причина: IsAlive объявлено как публичное поле (public bool IsAlive;), а System.Text.Json по умолчанию работает только со свойствами.


Способ 1: Превратить поле в автосвойство 
Добавить аксессоры { get; set; }

Способ 2: Включить сериализацию всех полей через атрибут
